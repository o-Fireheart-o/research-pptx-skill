# 파생판: 발표용 축약본, 영문판, 다음 문서

완성된 덱을 기준판으로 삼아 다른 판을 만든다. 기준판은 사용자가 최종 확인한 파일이다. 파생판을 만든 뒤
기준판이 바뀌면 파생판에도 반영할지 사용자에게 묻는다.

## 제출본 → 발표용 축약본

제출 문서는 읽히기 위한 것이고 발표 자료는 듣는 사람을 위한 것이다. 글자를 줄이는 것이 아니라 다시
고른다.

1. 발표 시간으로 본문 장수를 정한다(장당 1~2분).
2. 핵심 주장과 논리 사슬 표에서 **빠지면 주장이 무너지는 장**만 고른다. 보통 필요성 1~2장, 목표 1장,
   세부 목표별 내용(결과) 각 1~2장, 차별성 1장, 일정·기대 효과 각 1장.
3. 고른 장은 글을 줄이고 그림을 키운다. 한 장의 글은 제목 + 두세 줄.
4. 빠진 장은 버리지 않고 **보조 장표**(부록)로 뒤에 둔다. 질의응답에서 꺼내 쓴다. 예상 질문 목록을
   사용자와 만들고 각 질문에 답하는 장이 있는지 본다.
5. 발표 원고(슬라이드 노트)를 요청받으면 장당 발표 시간에 맞춰 쓴다. 한국어 기준 1분에 250~300자.
6. 무엇을 뺄지는 선택지로 제안하고 사용자가 정한다.

## 영문판(또는 국문판)

배치·그림은 그대로 두고 문구만 바꾼다.

### 먼저 정할 것
- **번역하지 않는 것**: 고유 명칭(과제명의 공식 영문명이 있으면 그것), 기관명의 공식 표기, 인명 표기,
  약어, 단위, 수식 기호. 공식 영문 표기는 사용자에게 확인한다.
- **용어표**: 분야 용어는 사용자의 논문·원고에 쓰인 표현을 따른다. 같은 원문은 항상 같은 번역.
- **문체**: 영문 슬라이드는 명사구나 짧은 문장으로. 한국어 개조식을 그대로 옮긴 조각 문장이 되지
  않게 한다.
- 그림 속 글자(그래프 축, 도식 상자)도 번역 대상이다. 그림 파일이라 고칠 수 없는 것은 목록으로 알린다.

### 만드는 순서
```
python -I <skill>/scripts/para_swap.py extract <기준판> <dict.json> hangul      (영문 → 국문이면 latin)
```
번역할 단락을 사전(`{원문: ""}`)으로 뽑는다. 값을 채운다. 단락 안에서 서식이 다른 부분은
`<f1>…</f1>` 표시를 유지한다.
```
python -I <skill>/scripts/para_swap.py build <기준판> <dict.json> <번역판>
python -I <skill>/scripts/fit_boxes.py <기준판> <번역판>
```
- `para_swap.py build`는 1번 슬라이드(표지)를 바꾸지 않는다. 표지는 직접 고친다.
- 표 안의 글과 차트의 글은 사전에 잡히지 않을 수 있다. `deck_check.py <번역판> --text`로 남은 원문을
  찾아 직접 고친다.
- 영어는 한국어보다 길어진다. 렌더링해서 넘치는 곳을 확인하고 문구를 줄인다.
- 사용자가 번역판을 직접 고친 뒤에는 `build`로 다시 만들지 않는다(고친 문구가 지워진다).

## 제안서 → 보고서

선정된 제안서는 다음 보고서의 기준이다.

- 제안서의 세부 목표, 정량 지표, 일정을 **문구 그대로** 보고서의 "목표 대비 실적" 표 왼쪽에 옮긴다.
- 제안서의 배경·필요성은 보고서에서 한두 장으로 줄인다.
- 제안서의 연구 내용 장 제목이 보고서의 수행 내용·결과 장의 뼈대가 된다.
- 계획과 달라진 점(방법 변경, 일정 지연, 목표 조정)을 사용자에게 물어 목록으로 만들고, 보고서에서
  사유와 함께 밝힌다.

## 지난 보고서 → 이번 보고서

- 지난 보고서의 "차년도 계획"이 이번 보고서의 "당해 목표"다. 문구를 대조한다.
- 지난 결과를 다시 실을 때는 지난 결과임을 표시하고, 이번 기간의 결과와 구분한다.
- 지난 문서의 파일을 복사해 시작하면 지난 날짜·연차·수치가 남기 쉽다. 검수에서 `deck_check.py --text`로
  전체 문구를 뽑아 연도·연차 표기를 훑는다.

## 연구 문서 → 다른 용도

논문 발표, 포스터, 홍보용 요약은 읽는 사람과 목적이 달라 구성부터 다시 잡는다. 이 스킬의 0~2단계를
그 용도로 다시 거친다.
