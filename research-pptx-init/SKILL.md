# 연구 PPT 작업 폴더 준비

사용자는 연구자이고 개발자가 아닐 수 있다. 이 스킬의 일은 **폴더를 대신 만들어 주고, 지금 무엇을 하면
되는지 한 화면으로 알려 주는 것**이다. 실제 PPT 제작은 `research-pptx` 스킬이 한다.

## 순서

1. **어디에 만들지 정한다.**
   - 지금 폴더가 비어 있거나 연구 자료만 있으면 지금 폴더에 만든다.
   - 지금 폴더가 다른 작업의 폴더로 보이면(코드, 다른 과제의 파일) 새 폴더 이름을 한 번 묻는다.
     과제 이름을 말했으면 그 이름으로 하위 폴더를 만든다.
   - 문서 이름을 사용자가 말했으면 `--name`으로 넘긴다. 말하지 않았으면 묻지 않는다.

2. **스크립트를 실행한다.** 스크립트는 `research-pptx` 스킬 안에 있다(이 스킬 폴더의 옆 폴더).
   ```
   python -I "<이 스킬 폴더>/../research-pptx/scripts/init_project.py" "<작업 폴더>" [--name "<문서 이름>"]
   ```
   - 없는 것만 만들고 기존 파일은 덮어쓰거나 지우지 않는다. 다시 실행해도 안전하다.
   - 스크립트가 없으면 `research-pptx` 스킬이 설치되지 않은 것이다. 설치 방법
     (https://github.com/o-Fireheart-o/research-pptx-skill)을 알려 주고 멈춘다.
   - Python이 없으면 폴더 다섯 개(`template`, `source`, `figures`, `output/backup`, `work`)만 직접 만들고,
     Python 설치가 필요하다고 알린다.

3. **폴더에 이미 있던 파일을 정리한다.** 스크립트가 "아직 분류 안 됨"으로 알려 준 파일이 있을 때만.
   - 문서·데이터와 그림은 옮겨도 되는지 한 번 묻고, 좋다고 하면 `--sort`를 붙여 다시 실행한다.
   - PPT 파일은 양식일 수도, 참고 자료일 수도 있다. 파일마다 어느 쪽인지 묻고 답에 따라 `template`이나
     `source`로 옮긴다. 추측으로 옮기지 않는다.
   - 사용자의 파일은 옮기기만 하고 지우거나 이름을 바꾸지 않는다.

4. **대화창에서 안내한다.** 스크립트 출력을 그대로 붙이지 말고 아래 틀로 짧게 다시 쓴다. 이미 채워진
   항목은 빼고, 사용자가 **지금 해야 할 일만** 번호로 남긴다.

   ```
   작업 폴더를 준비했습니다: <경로>

   지금 할 일
   1. template 폴더에 발표 양식이나 지난 발표 자료(.pptx)를 넣어 주세요. (꼭 필요합니다)
   2. source 폴더에 공고문, 초안, 논문, 데이터를 넣어 주세요. (하나 이상 필요합니다)
   3. 쓸 그림이 있으면 figures 폴더에 넣어 주세요. (없어도 됩니다)
   4. 다 넣으셨으면 이렇게 말해 주세요.
      "template 양식으로 연구 제안 발표 자료를 만들 거야. source 자료를 보고 스토리라인부터 잡아 줘.
       발표는 15분이야."

   같은 내용이 폴더의 시작하기.md에도 있습니다.
   ```

   - 양식과 자료가 이미 다 있으면 1~3을 빼고 "바로 시작할 수 있습니다"와 시작 문장만 보여 준다.
     이때 문서 종류와 발표 시간을 알려 달라고 덧붙인다.
   - 예시 문장의 "연구 제안 발표 자료", "15분"은 사용자가 말한 문서 종류와 시간으로 바꿔 쓴다.
   - 폴더 구조를 길게 설명하지 않는다. 궁금해하면 그때 설명한다.

## "지금 뭘 하면 돼?"라고 물을 때

이미 준비된 폴더에서 다음 할 일을 묻는 경우에도 같은 스크립트를 실행한다(아무것도 바꾸지 않고 상태만
알려 준다). 결과에 따라 답한다.

| 폴더 상태 | 안내 |
|---|---|
| 양식이나 자료가 비어 있음 | 무엇을 어느 폴더에 넣을지 |
| 양식과 자료가 있고 스토리라인이 없음 | 시작 문장 |
| 뼈대 덱(`storyboard.pptx`)이 있음 | PowerPoint에서 열어 흐름을 보고 고친 뒤 "읽어 줘" 또는 "이대로 만들어 줘" |
| `work/progress.json`이 있음 | `research-pptx` 스킬의 `progress.py show`로 단계와 남은 장을 확인해 지금 단계에서 사용자가 할 일을 알려 준다 |

## 하지 않는 것

- 스토리라인이나 슬라이드를 만들지 않는다. 사용자가 시작 문장을 말하면 그때 `research-pptx` 스킬이 맡는다.
  다만 사용자가 준비와 제작을 한 번에 요청했고("폴더 만들고 바로 시작해 줘") 양식과 자료가 이미 있으면,
  안내를 한 줄로 줄이고 바로 `research-pptx` 스킬로 넘어간다.
- 양식 파일을 열어 분석하지 않는다(제작 단계의 일이다).
